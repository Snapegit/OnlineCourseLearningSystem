
## 🌟 项目简介

这是一个基于 **Java + SpringBoot + Vue + MySQL** 构建的完整网上课程学习系统，功能持续优化中...

### 🧩 功能模块一览

- 课程信息管理（课程分类·课程信息·课程学习·学习进度）
- 学习计划管理（学习计划·计划进度）
- 作业信息管理（作业信息·提交作业）
- 成绩信息管理
- 在线交流管理
- 试卷管理（试卷·试题·考试记录·错题本）
- 用户管理（用户·教师）
- 论坛管理
- 前台课程信息·试卷列表·作业信息·论坛交流
- 个人中心

## ⚙️ 运行环境与工具要求

为了确保项目顺利运行，请确认您的开发环境满足以下条件：

### ✅ 推荐配置
- **Java**: JDK 1.8  
- **MySQL**: 8.0.41  
- **Node.js**: 16.20.2  

⚠️ *温馨提示：版本不一致可能导致依赖冲突或启动失败。*

### 🛠️ 开发工具推荐
- **后端开发**: IntelliJ IDEA 2022+  
- **前端开发**: VS Code  
- **数据库管理**: Navicat / DBeaver / MySQL Workbench  ...
